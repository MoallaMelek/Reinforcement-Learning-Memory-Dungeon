# Dungeon With Amnesia reproducibility checklist

- [ ] Record training and evaluation random seeds.
- [ ] Keep held-out maps separate from training maps.
- [ ] Log checkpoint identifiers and environment configuration.
- [ ] Compare feed-forward, history-based, and recurrent baselines under matched conditions.
- [ ] Run hidden-state reset ablations on paired episodes.
- [ ] Report episode counts and uncertainty, not only best-run success rates.
- [ ] State clearly that the showcased rune-cue retention does not establish general semantic memory.

Keep raw experiment records alongside summarized figures.
